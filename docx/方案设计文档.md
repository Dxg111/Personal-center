## 二、技术选型

### 2.1 选型总览

| 层级 | 技术 | 版本建议 | 选择理由 |
|------|------|----------|----------|
| **后端框架** | FastAPI | 0.115+ | 现代异步框架，自动生成 OpenAPI 文档，类型提示友好，Python 生态最适合快速 API 开发 |
| **ORM** | SQLModel | 0.0.22+ | FastAPI 作者出品，基于 SQLAlchemy + Pydantic，模型定义一次搞定 ORM + 数据校验 |
| **数据库** | SQLite | 3.x | MVP 阶段零配置、单文件、无需额外服务；后续可无缝切换 PostgreSQL |
| **认证** | python-jose + passlib | 3.3+/1.7+ | JWT Token 认证，bcrypt 密码哈希，前后端分离标准方案 |
| **前端框架** | Vue 3 + Vite | 3.4+/5.x | 上手快、模板语法直观、组合式 API 灵活；Vite 热更新极快 |
| **UI 样式** | Tailwind CSS | 3.4+ | 原子化 CSS，快速实现科幻深色风格，无需写大量自定义 CSS |
| **路由/状态** | Vue Router + Pinia | 4.x/2.x | Vue 官方标配，管理端路由守卫做权限控制 |
| **HTTP 请求** | Axios | 1.x | 拦截器统一处理 Token 注入和错误 |
| **Markdown 渲染** | marked + DOMPurify | 14.x/3.x | 前端渲染 Markdown，DOMPurify 防 XSS |
| **动效** | GSAP | 3.12+ | 鼠标光斑跟随、视差滚动、扫描线动画等复杂动效的行业标准 |
| **富文本编辑** | Tiptap | 2.x | 基于 ProseMirror 的所见即所得编辑器，支持 Markdown，管理端写作用 |
| **图片上传** | 本地 static 目录 | — | MVP 阶段图片存服务器本地，通过 `/static/uploads/` 访问；后续可接 OSS |

### 2.2 为什么选这套组合

**后端选 FastAPI 而不是 Django：**
- Django Admin 默认样式不符合"科幻工科风格"，管理端页面需要完全自定义，Django Admin 的价值大打折扣
- FastAPI 代码更轻量，API 自动文档（`/docs`）开发时直接可用
- SQLModel 让数据模型定义极其简洁

**前端选 Vue3 而不是 React：**
- 模板语法更直观，个人项目维护成本低
- Vue3 + Vite 启动快，HMR 秒级
- Tailwind + Vue 的组合在中文社区资料丰富

**数据库选 SQLite（todo：使用MySQL）：**

- 个人站日活极低，SQLite 性能完全够用
- 单文件数据库，备份就是复制文件
- SQLModel 支持后续一行配置切 PostgreSQL

## 四、数据库设计

### 4.1 表结构

#### 4.1.1 admin_user（管理员表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int PK | 主键 |
| username | str unique | 登录用户名 |
| hashed_password | str | bcrypt 哈希后的密码 |
| created_at | datetime | 创建时间 |

> MVP 阶段只有一个管理员账号，首次启动时通过脚本创建。

#### 4.1.2 project（项目表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int PK | 主键 |
| title | str | 项目标题 |
| summary | str | 一句话简介（列表卡片显示） |
| content | text | 正文（Markdown 格式） |
| cover_image | str / nullable | 封面图 URL |
| tech_stack | str | 技术栈标签，逗号分隔存储（如 "Vue3,FastAPI,Tailwind"） |
| demo_url | str / nullable | 演示地址外链 |
| github_url | str / nullable | GitHub 地址外链 |
| category | str | 分类：`project`（项目）/ `work`（作品） |
| is_published | bool | 是否发布：False=草稿，True=已发布 |
| views_count | int | 浏览量，默认 0 |
| sort_order | int | 排序权重（数字越小越靠前），用于首页重点项目展示 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

#### 4.1.3 profile（个人信息表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int PK | 主键（单行表，只有一条记录） |
| name | str | 姓名/昵称 |
| avatar_url | str | 头像图片地址 |
| bio | str | 一句话简介 |
| typing_slogan | str | Hero 区打字机效果的文案 |
| wechat | str / nullable | 微信号 |
| email | str / nullable | 邮箱 |
| github_url | str / nullable | GitHub 主页链接 |
| updated_at | datetime | 更新时间 |

### 4.2 数据库 ER 关系

```
admin_user (1条)     project (多条)     profile (1条)
┌──────────┐        ┌──────────────┐    ┌──────────────┐
│ id (PK)  │        │ id (PK)       │    │ id (PK)      │
│ username │        │ title         │    │ name         │
│ password │        │ summary       │    │ avatar_url   │
└──────────┘        │ content       │    │ bio          │
                    │ cover_image   │    │ wechat       │
                    │ tech_stack    │    │ email        │
                    │ category      │    │ github_url   │
                    │ is_published  │    └──────────────┘
                    │ views_count   │
                    │ sort_order    │
                    └──────────────┘
```

## 五、API 接口设计

### 5.1 公开接口（无需登录）

| 方法 | 路径 | 说明 | 对应功能 |
|------|------|------|----------|
| GET | `/api/profile` | 获取个人信息 | MVP-01 首页首屏 |
| GET | `/api/projects?category=project&published=true` | 项目列表（只返回已发布的） | MVP-03 分类切换 |
| GET | `/api/projects?category=work&published=true` | 作品列表 | MVP-03 |
| GET | `/api/projects/featured?limit=3` | 首页重点项目（sort_order 最靠前的3个已发布项目） | MVP-02 |
| GET | `/api/projects/{id}` | 项目详情（返回时 views_count +1） | MVP-04, MVP-08 |

### 5.2 管理接口（需要 JWT 认证）

| 方法 | 路径 | 说明 | 对应功能 |
|------|------|------|----------|
| POST | `/api/auth/login` | 登录，返回 JWT Token | MVP-09 |
| GET | `/api/admin/projects` | 后台项目列表（含草稿，所有状态都返回） | MVP-10 |
| POST | `/api/admin/projects` | 新建项目（可直接发布或存草稿） | MVP-11, MVP-13 |
| PUT | `/api/admin/projects/{id}` | 编辑项目 | MVP-11 |
| DELETE | `/api/admin/projects/{id}` | 删除项目 | MVP-12 |
| PUT | `/api/admin/projects/{id}/publish` | 切换发布/草稿状态 | MVP-13 |
| GET | `/api/admin/profile` | 获取个人信息（编辑用） | MVP-14 |
| PUT | `/api/admin/profile` | 更新个人信息 | MVP-14 |
| POST | `/api/admin/upload` | 上传图片（封面、头像），返回 URL | MVP-11 封面图 |

### 5.3 认证机制
- 登录成功后返回 `access_token`（JWT，有效期 24 小时）
- 前端 Axios 拦截器自动在请求头加 `Authorization: Bearer <token>`
- 管理端路由守卫：未登录访问 `/admin/*` 自动跳转到 `/admin/login`

## 六、前端页面与路由

### 6.1 路由表

```
/                       → Home.vue（首页）
/project/:id            → ProjectDetail.vue（项目详情）
/admin/login            → Login.vue（管理端登录）
/admin                  → Dashboard.vue（后台仪表盘，重定向到 /admin/projects）
/admin/projects        → ProjectList.vue（项目列表）
/admin/projects/new     → ProjectEdit.vue（新建项目）
/admin/projects/:id/edit → ProjectEdit.vue（编辑项目）
/admin/profile         → ProfileEdit.vue（个人信息编辑）
/:pathMatch(.*)*        → NotFound.vue（404）
```

### 6.2 核心页面说明

#### 6.2.1 首页 Home.vue（访客端）
- **Hero 区**：工程仪表盘风格
  - 顶部状态灯（绿色闪烁点，表示"系统在线"）
  - 打字机效果 slogan
  - 网格线背景 + 扫描线动画
  - 头像 + 姓名 + 一句话简介
  - 联系方式按钮
- **重点项目区**：调用 `/api/projects/featured?limit=3`，展示 3 张项目卡片
- **分类切换区**：项目 / 作品 两个 Tab，一键切换，不跳转页面
  - 切换时调用对应 category 的接口
- **页脚**：终端命令风格（`$ whoami` → 输出个人信息）

#### 6.2.2 项目详情 ProjectDetail.vue
- 面包屑导航（首页 / 项目 / 标题）
- 封面图
- 标题 + 简介
- 技术栈标签
- 外链按钮（演示地址 / GitHub）
- Markdown 正文渲染（marked + DOMPurify）
- 底部显示浏览量

#### 6.2.3 管理端登录 Login.vue

- 深色科幻风格登录卡片
- 用户名 + 密码输入框
- 登录按钮
- 失败提示

#### 6.2.4 项目列表 ProjectList.vue

- 顶部统计：总数 / 已发布 / 草稿
- 表格展示：标题、分类、状态、浏览量、创建时间、操作（编辑/删除/发布切换）
- 右上角"新建项目"按钮

#### 6.2.5 项目编辑 ProjectEdit.vue

- 表单字段：标题、简介、分类（项目/作品）、封面图上传、技术栈标签、演示链接、GitHub链接、正文编辑器（Tiptap）
- 底部两个按钮：
  - **存草稿**（保存但不发布）
  - **发布**（保存并上线）

## 七、视觉风格实现方案

### 7.1 设计基调
- **主色调**：深色背景 `#0a0e1a`（深蓝黑），主色 `#00ff88`（荧光绿，终端绿），辅助色 `#00d2ff`（科技蓝）
- **字体**：正文用系统无衬线字体，代码/终端元素用 `JetBrains Mono` 或 `Fira Code` 等等宽字体

### 7.2 科幻元素实现方式

| 效果 | 实现方式 |
|------|----------|
| 网格线背景 | CSS `background-image` 线性渐变画网格，opacity 很低 |
| 扫描线动画 | 一个固定高度的半透明白色横条，CSS animation 从上到下循环移动 |
| 鼠标光斑跟随 | GSAP 监听 mousemove，一个圆形径向渐变 div 跟随鼠标，带轻微延迟 |
| 打字机效果 | JS 逐字输出，光标用 CSS `::after` 加闪烁动画 |
| 状态指示灯 | 小圆点，CSS `animation: pulse` 呼吸闪烁 |
| 终端风格页脚 | 黑底 + 等宽字体 + 绿色文字，模拟命令行输出 |
| 卡片边框 | 1px 边框用主色 30% 透明度，hover 时变亮 + 轻微上浮 |

### 7.3 Tailwind 主题配置
在 `tailwind.config.js` 中扩展颜色和动画：
```js
theme: {
  extend: {
    colors: {
      'bg-dark': '#0a0e1a',
      'bg-card': '#111827',
      'neon-green': '#00ff88',
      'neon-blue': '#00d2ff',
    },
    fontFamily: {
      'mono': ['JetBrains Mono', 'Fira Code', 'monospace'],
    },
    animation: {
      'scanline': 'scanline 4s linear infinite',
      'blink': 'blink 1s step-end infinite',
      'pulse-dot': 'pulse-dot 2s ease-in-out infinite',
    }
  }
}
```

## 九、安全考虑

| 风险 | 措施 |
|------|------|
| SQL 注入 | SQLModel ORM 参数化查询，不拼接 SQL |
| XSS 攻击 | 前端 Markdown 渲染用 DOMPurify 清洗 HTML |
| 密码泄露 | bcrypt 哈希存储，不存明文 |
| JWT 伪造 | 密钥存在 .env 环境变量，不硬编码 |
| 接口未授权访问 | 所有 /api/admin/* 接口加 JWT 认证依赖 |
| 文件上传风险 | 限制上传类型（jpg/png/webp）和大小（5MB），重命名文件 |

1. **文章/博客模块（P1）**：project 表的 `category` 字段已经支持扩展，后续加 `article` 分类即可复用 CRUD 逻辑
2. **项目扩展标签（P1）**：tech_stack 目前是逗号分隔字符串，后续可拆成独立 tag 表
3. **多图片上传**：上传接口通用化，后续可扩展为项目多图展示
4. **深色/浅色切换（P2）**：Tailwind 本身支持 dark mode，后续加 class 切换即可
5. **GitHub 贡献图（P2）**：首页加个组件嵌入即可，不影响现有架构

## 十一、开发环境启动方式

### 后端
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
- API 文档：http://localhost:8000/docs

### 前端
```bash
cd frontend
npm install
npm run dev
```
- 前端地址：http://localhost:5173
